OPEN SOURCE / MCP CAPABILITY LAYER

More capability.
Less context.

Your agent doesn’t need the entire tool catalog in its prompt. It needs a good way to find the right action.

Action Hub puts MCP servers and skills behind one fixed tool. Search for a capability, load its schema, execute when ready.

03 / DESIGN NOTES & OPEN QUESTIONS

A smaller surface.
Not a free lunch.

The architecture moves complexity. It doesn’t eliminate it. These are real tradeoffs raised in the community discussion.

01
APPROVAL VISIBILITY

One tool can hide the action that matters.

hutsonlabs’ concern, paraphrased: a host that only sees action_hub may not expose the downstream action in its normal approval UI. A single entry point is not a substitute for legible consent.

Current binding: approval tokens are bound to the action and exact arguments via a canonical argument hash. They are single-use and expire after five minutes by default. The lifetime is configurable, capped at one hour. See the approval design.

Visibility gap: the execute span does not yet expose the argument hash or upstream version. Approval binding exists; those telemetry fields do not. This site does not promise a shipped fix.

Inspect the telemetry contract {{icon:arrow-up-right}}
02
DISCOVERY QUALITY

“Help me with this” is a hard search query.

QuanTradin’s concern, paraphrased: search-first discovery can miss capabilities when a task is vague or goal-only rather than phrased in tool vocabulary.

Current mitigations: the compressed list_servers helper exposes the connected integrations and domain words. Pinned bundles can keep known task capabilities close at hand. The 30 goal-only queries are gated separately so aggregate improvements cannot hide this weak spot.

Proposed tradeoff, not the shipped default: put a tiny static capability index in the stable system prompt to give the model a starting map.

03
THE REAL TOKEN BUDGET

A map has a cost. So does a wrong turn.

BC_MARO’s tradeoff, paraphrased: a tiny static capability index in a stable system prompt may help discovery, but adds permanent token overhead.

False-positive searches and repeated discovery can erase the savings from a small baseline. False-positive search cost is a metric to track, not an existing measured result. Evaluate the whole path to a useful action, not just the initial tool definition.

04 / GET STARTED

Try the capability layer.
Keep your MCP host.

A standalone binary includes the runtime, CLI, and MCP server. Or build from source with Node.js 20.11+.

macOS / Linux

brew tap 1solomonwakhungu/tap
brew install action-hub

Windows

winget install SolomonWakhungu.ActionHub

Prefer a binary download? Use the latest release and verify SHA256SUMS.txt.

1

Configure your downstream servers. Start with config/servers.example.json and copy it to config/servers.json in a source checkout.

2

Register one MCP server in your host. Point your host configuration at the installed binary:

{
  "command": "action-hub",
  "args": ["start"]
}
